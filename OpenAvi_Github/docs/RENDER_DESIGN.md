# au2-render 設計メモ

> **状態: 試作実装済み**（図形・画像・テキスト・色調補正、ゴールデンテストあり）。プレビューへ組み込み済み（`PreviewRenderer`）。

> ROADMAP 段階 A の最初の成果物。UI から独立した **ヘッドレス合成エンジン**。
> プレビューと動画書き出しの両方が同じコードで絵を作ることで、「見た目と出力が違う」問題を構造的に防ぐ。

## 目的と非目的

**目的**
- `Scene` + フレーム番号 → RGBA 画像、を GPU（wgpu）で作る。ウィンドウ不要。
- 将来のフィルタ・合成モード・3D/カメラ・クリッピングを載せられる骨組みにする。
- 参照画像との比較（ゴールデンイメージテスト）を回せるようにする。

**非目的（試作段階ではやらない）**
- テキストの装飾（影・縁取り・文字間隔・太字/斜体・揃え・文字毎個別オブジェクト）。基本の単色テキストは実装済み
- 合成モード、クリッピング、`.anm` 等の Lua 実行（3D・カメラ制御・グループ制御は段階 B で実装。下の「3D」節）
- デコード自体（メディアは `MediaSource` トレイト越しに受け取るだけ。常駐 ffmpeg デコードは `au2-media/src/stream.rs`）

## テキスト

- `ab_glyph` で CPU ラスタライズし（`text.rs`）、色付きの RGBA 画像にして通常のテクスチャスプライトとして描く。拡大率はラスタライズ時に反映（拡大してもぼやけない）。
- フォントは `Renderer::set_font()` か `load_system_font()`（OS の日本語フォントを探索）で設定する。未設定なら描かない。
- 結果は (サイズ, 色, 本文) をキーにテクスチャキャッシュされる。
- 縁取り・影などの装飾は、フィルタパス（段階 C）を物体単位にかけられるようになってから実装する。

## 全体構成

```
Scene + frame ──► 評価 (eval) ──► 描画コマンド列 ──► GPU 合成 ──► RGBA 読み戻し
                  │ トラック評価      Sprite / Filter     │ ping-pong
                  │ フェード等         (レイヤー順)        │ フレームバッファ
```

| モジュール | 役割 |
|---|---|
| `gpu` | wgpu の Instance/Adapter/Device/Queue。`headless()` と、eframe の既存 Device を借りる `from_parts()` |
| `eval` | オブジェクト → `DrawParams`（標準/拡張描画の全項目）。フェード・組み込みアニメーション効果・グループ制御・カメラ制御込み。射影変換（`Homography`）と選択枠（`ObjectBounds`）もここで計算する。**プレビューと共有する唯一の評価元**にする |
| `renderer` | パイプライン保持、コマンド列の構築と記録、フレーム読み戻し |
| `shaders/*.wgsl` | スプライト（テクスチャ/SDF 図形）とフィルタ |
| `media` | `MediaSource` トレイト（画像・動画フレームの供給元） |

## 描画モデル

- 座標系: シーン中心が原点、+x 右、+y 下、単位はシーンのピクセル（AviUtl と同じ）。
- フレームバッファ: `Rgba8Unorm`（**ガンマ空間のまま**扱う。AviUtl も sRGB 変換をしない）。
  - 将来 16bit（`Rgba16Float`）へ切り替えられるよう、フォーマットは 1 か所で定義する。
- ブレンド: ストレートアルファの「over」（合成モードは下の「合成モード・クリッピング」）。フィルタを物体単位にかける段階（B/C）で、プリマルチプライドへの切替を検討する。
- **スプライト**: 1 オブジェクト = 1 クワッド。頂点は頂点 ID から生成し、行列は使わず `center / half / angle` の uniform で回転・拡大。
- ブレンド: ストレートアルファの「over」。フィルタを物体単位にかける段階（B/C）で、プリマルチプライドへの切替を検討する。
- **スプライト**: 1 オブジェクト = 1 クワッド。頂点は頂点 ID から生成し、`SpriteUniform::ext` の射影変換（3x3）で画面へ置く（下の「3D」節）。
  `ext` が全て 0 のスプライト（背景など）は従来どおり `center / angle` の 2D 配置。
  - テクスチャ: 画像・動画フレーム
  - SDF 図形: 円・四角・多角形・星をフラグメントで解析的にアンチエイリアス描画（テッセレーション不要）
- **フィルタオブジェクト**: 下位レイヤーの合成結果全体にかかる全画面パス。フレームバッファをコピーして読み、書き戻す（ping-pong）。
  - 試作では「色調補正」だけを実装し、仕組みを証明する。
- uniform は 1 フレーム分を 1 つのバッファにまとめ、動的オフセットで参照する（`write_buffer` の後勝ち問題を避けるため）。

## 合成モード・クリッピング

> 実装: `blend.rs`（モードの読み取り・クリッピング元の判定）、`shaders/sprite_fragment.wgsl`（式）、`renderer.rs`（パスの記録）。
> テスト: `tests/blend.rs`（モードごとの手計算の画素値・クリッピング・`.exo` 経由・ゴールデン `blend_modes.png`）。

- **合成モード**は標準描画（無ければ拡張描画）の `blend`。`.exo` の番号 0〜12、または `.aup2` の表示名（`通常`〜`差分`）を受け付け、
  不明な値は通常として扱う（`BlendMode`）。シェーダへは `SpriteUniform::blend = [モード, クリッピング, 0, 0]` で渡す。
- **描画経路**（`SpritePath`）
  - 通常・クリッピング無し: 従来どおり、連続するスプライトを 1 パスにまとめる（`fs`。グループ 2 を使わない）。
  - 合成モード ≠ 通常: 描く直前にフレームバッファ全体を scratch へコピーし（色調補正と同じ ping-pong）、1 スプライト 1 パスで描く（`fs_ext`）。
    シェーダは `textureLoad` で同じ画素の下地を読む。3D/カメラ変換後の描画範囲は Rust 側で分からないので、コピーは常に全画面
    （1920x1080 で約 8MB/回）。
- **式**（ガンマ空間・0〜1。S = 上（このオブジェクト）のストレート色、D = 下地。結果は 0〜1 に収める）

  | 番号 | モード | B(S, D) |
  |---|---|---|
  | 0 | 通常 | S |
  | 1 | 加算 | S + D |
  | 2 | 減算 | D − S |
  | 3 | 乗算 | S·D |
  | 4 | スクリーン | 1 − (1 − S)(1 − D) |
  | 5 | オーバーレイ | D < 0.5 なら 2SD、それ以外 1 − 2(1 − S)(1 − D) |
  | 6 | 比較(明) | max(S, D) |
  | 7 | 比較(暗) | min(S, D) |
  | 8 | 輝度 ⚠ | YCbCr(BT.601) で Y = S の Y、CbCr = D の CbCr |
  | 9 | 色差 ⚠ | Y = D の Y、CbCr = S の CbCr |
  | 10 | 陰影 ⚠ | S + D − 1（焼き込みリニア） |
  | 11 | 明暗 ⚠ | D + 2S − 1（リニアライト） |
  | 12 | 差分 | \|S − D\| |

- **不透明度の扱い**: B' = mix(S, B, Ad)（下地が透明な所は通常合成に寄せる。W3C Compositing と同じ）を色、上の不透明度 As を
  アルファとして出力し、通常と同じハードウェアの「over」で合成する → 結果色 = mix(D, B', As)、結果アルファ = As + Ad(1 − As)。
  つまり**上の不透明度（透明度・フェード・アンチエイリアス・画像のアルファ・クリッピングのマスク）がそのまま効果の強さ**になる。
  現状のフレームバッファは背景が不透明な黒なので常に Ad = 1。
- **上のオブジェクトでクリッピング**（`TimelineObject::clipping` または `Layer::clip_above`）
  - クリッピング元 = タイムラインで**すぐ上の行**（レイヤー番号 − 1、描画順では直前）にある、このフレームのメディアオブジェクト。
  - クリッピング元は自分の順番ではフレームバッファに描かない。クリッピングする側を描く直前に、フレームバッファと同サイズの
    マスク（`R8Unorm`）を 0 で消し、クリッピング元の不透明度だけを描く（`fs_mask`。頂点シェーダは共通なので 3D 変換もそのまま効く）。
    クリッピングする側は `fs_ext` でマスクの値を自分の不透明度に掛ける。合成モードとも併用できる（マスクを掛けた不透明度で合成）。
  - ステンシルではなくマスクテクスチャにしたのは、クリッピング元のアンチエイリアスと半透明をそのまま掛けられるため。
## 3D（拡張描画・カメラ制御・グループ制御）

- 座標系: +x 右、+y 下、+z 奥。カメラ制御が無くても、目の位置 z = -1024・焦点距離 1024 の透視投影をかける（z = 0 の面が等倍、Z = 1024 で半分）。
- 物体は平面なので、物体ローカル座標（拡大率を掛けた後のピクセル）→ 画面座標は 3x3 の射影変換 `H` で書ける:
  `world(q) = P + L·((q.x, q.y, 0) - 中心·拡大率)`、`L = グループの回転 · Rx·Ry·Rz · diag(縦横比)`、`P = グループ(X, Y, Z)`、それをカメラ座標へ移して透視。
  CPU（`eval.rs`）で `H` を作り `ext` に詰める。並び: `ext[0] = (m00, m01, m02, 1)`、`ext[1] = (m10, m11, m12, 0)`、`ext[2] = (m20, m21, m22, near)`、`ext[3]` は予備。
- 頂点シェーダはクリップ座標 `(X, -Y, w - near, w)` を出す。`w` に奥行きが入るので、フラグメントへ渡す `local`（物体ローカルのピクセル座標）と
  そこから作る UV は透視補正付きで補間され、SDF 図形の被覆もローカル座標のまま正しい。カメラの手前（目から 1px 未満）・後ろの部分は GPU のクリップで切り取られる。
- 裏面: `det(H) <= 0`（面の向きが反転、または真横）なら裏。「裏面を表示しない」なら描かない。表示する場合は自然に左右反転して見える。丸ごとカメラの後ろにあるものも描かない。
- グループ制御: 下の `range` レイヤー（0 = 下全て）のオブジェクトに `p ↦ (X,Y,Z) + 拡大率 · 回転 · p` を掛ける。拡大率は `DrawParams::zoom` にも掛ける（テキストを拡大後の大きさでラスタライズするため）。
  範囲が重なるときは最も近いグループ制御が効き、グループ制御自身も上のグループ制御の範囲内ならその子になる。
- カメラ制御: 自分より下のレイヤーのうち `camera_target`（`.exo` の `camera=1`）のオブジェクトだけをそのカメラで描く。それ以外は既定の視点のまま。
- 選択枠: `ObjectBounds::corners` が射影後の四隅（台形）。`center / half / angle` は四隅に当てはめた回転矩形（2D なら厳密）。一部がカメラの後ろにあるときは記録しない。
## 時間制御・シーン・フレームバッファ・直前オブジェクト

- **時間制御**（`au2_core::scene_time`）: レイヤー 1 から順に、各レイヤーが見るフレームを決める（`layer_frames`）。表示中の時間制御は、
  下のレイヤー（`range` 枚。0 = すべて）の時刻を置き換える。描画ループはレイヤーごとに置き換え後のフレームでオブジェクトを探し、
  その相対フレームでトラック・動画の再生位置を評価する。時間制御そのものも上の時間制御で置き換え済みの時刻で評価する（入れ子は合成）。
- **シーン**: `Renderer::render_project(&Project, シーン番号, frame, media)` で、シーンオブジェクトが同じプロジェクトの別シーンを表示できる
  （`render_to_framebuffer(&Scene, …)` は従来どおり。参照先が無いのでシーンオブジェクトは描かない）。
  子シーンは、親の `targets` を退避して入れ子の深さごとの作業用フレームバッファへ同じ `render_scene` で描き（背景は透明）、
  オブジェクト専用のテクスチャへ写してから親のスプライトにする。GPU への投入順で前後関係を保つ。
  描画中のシーン（祖先）を参照するものと、深さ 8 を超えるものは描かない。
- **フレームバッファ**: `Op::Snapshot` でそこまでの合成結果を写し取り（「フレームバッファをクリア」なら背景で塗り直し）、
  写しを画面サイズのスプライトとして標準描画で置く。
- **直前オブジェクト**: 描画順で直前に描いたスプライトの絵を、直前オブジェクト自身の位置・拡大率・回転・透明度で描き直す。
- **シーン(音声)**: `au2_audio::mix_project` が参照先シーンの必要な範囲を再帰的にミックスして足す（循環は鳴らさない）。

## プレビューへの組み込み

- `au2-app` が eframe の `RenderState`（device/queue）を `Gpu::from_parts` で共有し、`render_to_framebuffer()` の結果を
  `register_native_texture` で egui に登録して表示する。CPU への読み戻しは無い。
- egui はテクスチャを sRGB として扱うため、表示には **sRGB 解釈のビュー**（`framebuffer_view()`）を使う。
  Unorm のまま渡すと二重にガンマ補正されて白っぽくなる（実際に起きた）。
- 選択枠は `object_bounds()` の四隅（3D の射影後の四角形）から egui で描く。
- 未対応: アイドル時の再描画抑制（今は UI 再描画のたびに描く）、再生中の非同期デコード。

## 同期・スレッド

- 試作は同期 API（`render()` が読み戻しまで待つ）。UI への組み込み段階では、書き出しスレッドと
  プレビュー用の非同期読み戻し（またはテクスチャ直接表示）を分ける。
- 書き出しはヘッドレス、プレビューは eframe の wgpu Device を借りて **読み戻し無しで** 画面にテクスチャを出すのが最終形。

## テスト方針

- GPU が無い環境（CI の Linux など）ではテストを **スキップ**する（アダプタ取得失敗＝スキップ）。
- ゴールデンイメージ: `crates/au2-render/tests/golden/*.png`。許容誤差付きで比較し、
  `UPDATE_GOLDEN=1 cargo test -p au2-render` で更新する。GPU/ドライバ差を見越して 1 チャンネルあたり ±3、画素の 0.1% までの超過を許容。
- 段階 E で、実 AviUtl の出力画像を参照画像として同じ仕組みに載せる。

## 未決事項

- テキスト装飾（縁取り・影）の表現方法。フォント名（`font` パラメータ）から実フォントへの解決
- 移動方法（`au2-core/src/track.rs`）の近似。実 AviUtl の式は未照合:
  - 移動量指定(5): `param` の第 1 値を総移動量とし `開始値 + 量 × t`（終了値は無視。`param` 無しは直線）。実際は「1 フレームあたりの量」の可能性あり。
  - ランダム移動(6): `param` = `変化間隔,シード`。区間の開始・終了値の間で splitmix64 による決定的乱数を、間隔フレームごとに保持。実 AviUtl の乱数列とは一致しない。
  - 反復移動(7, `MoveKind::Other(7)`): `param` = 往復回数（既定 1）。開始値↔終了値の三角波。加減速は往路・復路の各片道に適用。
  - 回転・スクリプト移動(`.tra`)は未対応（直線補間で代用）。
- テキスト（段階 B / U2 で実装した**近似**。段階 E で実 AviUtl の参照画像と突き合わせて確定させる）:
  - 影: 本体を (字の高さ/20 ≥ 1px, 同) だけ右下にずらして `color2` で描く。「影付き(薄)」は不透明度 50%。ぼかしなし。
  - 縁取り: 本体のカバレッジを半径 字の高さ/20（細は /40、最小 1px）の円盤で膨らませて `color2` で下に敷く。
  - 太字: 合成太字（字を横へ 字の高さ×4% ≥ 1px の範囲に複数回重ね、字送りもその分広げる）。斜体: 約 12 度（傾き 0.21）のせん断。
  - 等幅: 半角（ASCII）は 字の高さ/2、それ以外は 字の高さ の升に中央寄せ（実 AviUtl は MS ゴシック系の等幅）。
  - 揃え: 画像内の行揃えと、オブジェクト位置に対するブロックの位置合わせ点（左/中/右 × 上/中/下）。位置合わせ点は回転・拡大の中心でもある（実際は要確認）。
  - 表示速度: 文字/秒 × 相対フレーム/fps の整数部だけ先頭から表示（0 = 全部）。全文字でレイアウトし、未表示の字は描かないだけなので位置は動かない。
  - 文字間隔 `spacing_x/y` は px（拡大率を掛ける）。行送り＝フォントの行高＋spacing_y。
  - フォント名: 名前を正規化（小文字・空白/記号除去・全角→半角）してインストール済みフォントのファイル名と照合（完全一致→部分一致の短い名前）。
    MS UI Gothic / MS ゴシック / メイリオ / 游ゴシック / MS 明朝 / ヒラギノ… は別名表で近い実在フォントへ。見つからなければ既定フォント。.ttc は先頭の書体のみ。
  - 未対応: 「文字毎に個別オブジェクト」「移動座標上に表示する」「自動スクロール」「autoadjust」「soft」「precision」、書体の太さ違い（Bold ファイルの選択）。
- 色調補正の各項目（明るさ・輝度など）の正確な式。**試作の式は近似**で、実 AviUtl の参照画像で確定させる。
- **時間制御（近似）**: 「位置」は制御オブジェクトの長さに対する %（`t = 位置 / 100 × (長さ - 1)`。既定の 0 → 100 直線移動で恒等、100 → 0 で逆再生）。
  「繰り返し」n は、`t` を `長さ / n` で巻き戻す（先頭の 1/n 区間を等速で n 回）と解釈した。「コマ落ち」k は制御内の相対時刻を k フレーム単位に切り捨てる。
  負の時刻は制御の先頭に揃える。範囲は `range` 設定（グループ制御と同じ）か「対象レイヤー数」。範囲が重なる場合は下の時間制御が優先。
  音声には効かない（AviUtl でも時間制御で音声は逆再生されない、という解説に合わせた）。実 AviUtl との照合が必要
- **シーン（近似）**: `scene` 設定は `Project::scenes` の添字（0 = Root）か、数値でなければシーン名。再生位置・再生速度・ループ再生は動画ファイルと同じ式で、
  親子のフレームレートが違えば秒で換算する。ループしない場合、子シーンの長さを越えたら最後のフレームで止める（動画の終端と同じ扱い。実 AviUtl は未確認）。
  子シーンは透明背景に描くが、合成はストレートアルファの over のままなので、**半透明の部分は暗くなる**（プリマルチプライド化の検討と同じ問題）。
  入れ子の深さ 8 で打ち切り。自分自身・祖先を参照するシーンオブジェクトは何も描かない
- **フレームバッファ（近似）**: 写すのは「そのシーンでそこまでに描いた結果」（ルートなら黒背景込み）。クリアはルートでは黒、子シーンでは透明で塗り直す

- クリッピング（**推定**。実 AviUtl で確認する）
  - クリッピング元自身は描かない。
  - すぐ上の行にオブジェクトが無い（空・非表示レイヤー・フィルタ/制御オブジェクト・先頭レイヤー）場合、クリッピングする側は何も描かない。
  - マスクはクリッピング元の不透明度（透明度・フェードを含む）をそのまま使い、クリッピング元の合成モードは無視する。
  - 連鎖（クリッピング元自体もクリッピングしている）では、クリッピング元は描かれず、そのクリッピングは無視して素の形をマスクにする。

- **3D・カメラ・グループ制御の近似**（段階 E で実 AviUtl の参照画像と突き合わせる）:
  - 回転の合成順は `Rx·Ry·Rz`（物体に Z → Y → X の順）。各軸とも右手系の標準の回転（正の軸の向きへ見て時計回り）。実 AviUtl の順序・X/Y の向きは未確認
  - カメラ制御が無いときも z = -1024・焦点距離 1024 の透視をかける（標準描画の Z も大きさに効く）
  - 中心X/Y/Z: 拡大前のピクセルで、その点が座標 (X, Y, Z) に来る（正の中心X で絵は左へずれる）。拡大率は中心のまわりに掛かる
  - 縦横比: 正 = 横を `1 - a/100` 倍、負 = 縦を `1 + a/100` 倍
  - カメラの傾き: 正 = カメラが時計回りに傾く（映像は反時計回り）。視野角 0 = 焦点距離 1024、それ以外は `(画面の高さ/2) / tan(視野角/2)`（不連続）
  - 視線が真上・真下のときは +x を画面の右にする
  - グループ制御・カメラ制御の `range` が 0・未指定なら下のレイヤー全て。グループ制御の回転は「回転」と「X/Y/Z軸回転」の両方の名前を読む
  - 未対応: カメラ制御の目標レイヤー・深度ぼけ・Zバッファ/シャドー（描画順はレイヤー順のまま、奥行きでの並べ替えなし）、
    グループ制御の「同じグループのオブジェクトを対象にする」「上位グループ制御の影響を受ける」の切り替え（常に受ける）、カメラ効果（シャドー等）
  - アンチエイリアスの幅はローカル座標で 1px（フラグメント側の `0.5 - sd`）。3D で拡大されると縁がぼけ、縮むと鋭くなる。
